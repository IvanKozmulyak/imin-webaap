# imin.wtf — backlink strategy

A one-page investor/organizer landing has no content engine, so links come from
places that already talk about IMIN. Every link below is earned or owned — no
paid links, no directories that exist only to sell links.

Priority order: own properties → pages that already mention IMIN → directories → organizers → founder-led content.

## 1. Own properties (this week, zero cost)

| Where | Link | Owner |
|---|---|---|
| `app.imin.wtf` footer (imin-public) | "About IMIN" → `https://imin.wtf/` | Ivan |
| `dashboard.imin.wtf` sign-in page (imin-webapp) | logo → `https://imin.wtf/` | Ivan |
| LinkedIn company page — create if missing | website field | Bohdan |
| Both founders' LinkedIn profiles | website + featured post | each |
| Cal.com booking page | link in the event description | Bohdan |
| Email signatures (`@imin.support`) | one line | both |
| Organizer emails sent by the platform | footer "Powered by IMIN" → `imin.wtf` | Ivan |

## 2. Pages that already mention IMIN (ask for a live link)

- **Metz Startup Challenge** — winner listing, Feb 2026. Ask the organisers for a link on the results page.
- **Web Summit** startup profile pages, 2024 and 2025 editions.
- **University of Luxembourg Incubator** — Summer School cohort page, Jul 2026.
- Any press or newsletter that covered the win — search `"IMIN" Metz startup` monthly.

One short email each: who we are, the exact URL, where on their page it fits.

## 3. Startup directories (indexed, free, one afternoon)

Crunchbase · F6S · Wellfound · BetaList · EU-Startups database · French Tech / Luxembourg startup maps · Product Hunt (launch the Poster Studio as a product, not the landing).
Use the same name, one-line description and logo everywhere so the Organization entity stays consistent.

## 4. Organizer pages (compounding)

Every organizer event page on `app.imin.wtf/e/…` is a real, indexable page. Ask organizers — Vechirka first — to put that URL in their Instagram bio, Resident Advisor and Shotgun listings instead of a generic link. Those links land on `app.` but strengthen the whole domain.

## 5. Founder-led content (one per month)

Bohdan writes or talks about independent nightlife marketing: guest post, podcast, or a data note. Targets: Resident Advisor community, Mixmag, IQ Magazine, event-tech newsletters, Eventbrite-vs-DICE comparison blogs. Cite the "151M live-music fans" and loneliness stats with sources — cited numbers get quoted, and quotes get linked.

## Don't

Buy links, PBNs, link exchanges, comment spam, "submit to 500 directories" services. One good link beats fifty bad ones, and the bad ones can get the domain penalised.

## Measure

Search Console → Links report, monthly. Track: referring domains, top linked pages, and whether `imin.wtf` starts ranking for "IMIN nightlife" and "IMIN tickets" (brand queries first, then category).
