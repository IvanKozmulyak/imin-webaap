# imin-webapp

Placeholder landing page. Full app to be rebuilt from scratch.

## Stack

- Next.js 14 (App Router)
- Prisma + PostgreSQL (partner-request capture only)

## Setup

```bash
npm install
cp .env.example .env   # set DATABASE_URL
npm run db:migrate     # create partner_request table
npm run dev
```

## Preserved from the old app

- `app/api/partner-request/route.ts` — POST endpoint that captures partner/org email submissions.
- `prisma/schema.prisma` — `PartnerRequest` model backing that endpoint.

## SEO

`app/robots.ts`, `app/sitemap.ts`, `app/opengraph-image.tsx` and the metadata in `app/layout.tsx` are generated by Next at build time. `next.config.js` 301s `www.imin.wtf` to `imin.wtf` so there is one canonical origin — both hostnames must stay attached to the same Vercel project.

### Google Search Console

1. Add a **Domain** property for `imin.wtf` at https://search.google.com/search-console — it covers `app.` and `dashboard.` too. Verify with the DNS TXT record Google shows, at the registrar.
2. If DNS is not an option, add a **URL-prefix** property for `https://imin.wtf/` instead, pick *HTML tag*, copy only the `content="…"` value into `GOOGLE_SITE_VERIFICATION` in the Vercel project (Production), redeploy, then click *Verify*.
3. Sitemaps → submit `https://imin.wtf/sitemap.xml`.
4. URL inspection → `https://imin.wtf/` → *Request indexing*.

Backlink plan: `docs/seo-backlink-strategy.md`.
