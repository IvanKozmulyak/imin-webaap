# imin.wtf

The public site: the guest page at `/` and the creators page at `/pro`.

## Stack

- Static pages in `public/` (`index.html`, `pro/index.html`), vanilla JS with GSAP, ScrollTrigger, SplitText and Lenis. `next.config.js` rewrites `/` and `/pro` to them.
- Next.js 14 serves the API routes, `robots.txt`, `sitemap.xml` and the OG images.
- `public/assets/js/config.js` holds the links and the nights shown on the guest page (pinned by app.imin.wtf event id).

## Routes

- `GET /api/nights?ids=<uuid>,…&lang=en`: the pinned nights that are still on, read from the public imin API (cached 5 min).
- `POST /api/subscribe`: "Keep me posted"; emails the team.
- `POST /api/pitch`: "Send us your night"; emails the team.
- `POST /api/call-click`: beacon when someone opens the 20-minute call link.

## Setup

```bash
npm install
cp .env.example .env.local   # RESEND_API_KEY to send the team emails
npm run dev
npm test                     # unit tests, then check:i18n (translated pages in step with English)
npm run test:unit            # unit tests only (node --test)
```

## SEO

`app/robots.ts`, `app/sitemap.ts` and the `opengraph-image.tsx` files are generated by Next at build time; titles, descriptions, canonicals and JSON-LD live in each page's `<head>`. `next.config.js` 308s `www.imin.wtf` to `imin.wtf` so there is one canonical origin; both hostnames must stay attached to the same Vercel project.

### Google Search Console

1. Add a **Domain** property for `imin.wtf` at https://search.google.com/search-console (covers `app.` and `dashboard.` too) and verify it with the DNS TXT record at the registrar. The static pages carry no HTML-tag verification.
2. Sitemaps → submit `https://imin.wtf/sitemap.xml`.
3. URL inspection → `https://imin.wtf/` and `https://imin.wtf/pro` → *Request indexing*.

Backlink plan: `docs/seo-backlink-strategy.md`.
